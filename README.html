2. Variables de Transformación (ETL)

Normalización Geográfica: Uso de campos Country_Normalized para corregir errores de escritura.

Conversión Monetaria: Aplicación de tasas TRM para unificar USD, GBP, EUR y otros a COP.

Totalización: Creación de total_compensacion_cop sumando salario base y bonificaciones.

3. Paso a Paso del Modelado

  1. Carga: Importación de CSV a Looker Studio.
  2. Limpieza: Estandarización de nombres de ciudades y países.
  3. Cálculo: Creación de métricas para conversión de divisas.
  4. Visualización: Diseño de gráficos comparativos por Industria, Género y Experiencia.

4. Conclusión

Este modelo permite una comparación justa de salarios globales al unificar todas las métricas en Pesos Colombianos, garantizando una interpretación libre de sesgos por moneda o errores de digitación geográfica.
